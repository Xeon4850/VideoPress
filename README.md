# VideoPress 视频压缩工具

Windows 本地批量视频压缩，支持 NAS、复杂文件名、实时进度与双 FFmpeg 自动回退。

## 首次使用

1. 安装 Python 3.10 或更高版本，安装时勾选 **Add Python to PATH**。
2. 双击 **setup.bat**。窗口均为英文，这是为了避免不同 Windows 代码页导致批处理乱码和拆行错误。拖拽组件安装包已内置，优先离线安装，不依赖 PyPI 镜像。
3. 配置程序会下载两套 FFmpeg：
   - `ffmpeg-latest`：最新版，优先用于 RTX 4070 Laptop 等受支持设备。
   - `ffmpeg-compat`：FFmpeg 8.1.2，用于 GTX 1080 / Pascal 兼容。
4. 双击 **run.bat** 启动。

所有启动、配置文件及 Python 主程序均使用 ASCII 文件名和 ASCII 批处理内容。失败时窗口会停留，请查看 **setup.log**。

## 编码器调度

自动模式会对两套 FFmpeg 分别进行真实的一帧编码测试，而不是仅检查编码器名称。每个任务的回退顺序为：

1. 最新版 FFmpeg + NVENC。
2. FFmpeg 8.1.2 + NVENC。
3. 可用构建 + Intel QSV。
4. CPU libx264。

即使启动测试成功、正式压缩时新版 NVENC 仍然失败，也会自动用兼容版重试。状态栏会显示当前使用的编码器和 FFmpeg 版本。

FFmpeg 8.1.2 不会明显降低 GTX 1080 的 NVENC 硬件编码速度，因为编码主要由显卡固定功能单元完成。新版可能包含编码器参数和驱动支持改进，因此在 RTX 4070 上优先使用新版。

## 使用

- 拖入视频或目录，也支持按钮添加及递归扫描。
- 查看分辨率、编码、码率、大小、单文件进度和队列进度。
- 目标大小为原文件的 10%～90%，默认 45%。该比例是目标值，结果会略有偏差。
- 输出到源目录下的 `output`，或自定义目录。
- 完成后显示新大小及“新文件 ÷ 原文件”百分比。
- 支持中文、Emoji、空格和括号等复杂名称；重名自动编号，不覆盖源文件。
- 支持映射网络驱动器及 `\\NAS\共享目录` UNC 路径。

## 打包 EXE

运行 **build_exe.bat**，生成 `dist\VideoPress.exe`。将 `ffmpeg-latest` 和 `ffmpeg-compat` 两个目录复制到 EXE 同目录。

## NVIDIA 诊断

NVENC 选项始终显示，可手动强制尝试新版与兼容版。每次启动会生成 `hardware_detection.log`，记录 nvidia-smi、FFmpeg 版本和 NVENC/QSV 实测的完整输出。排查 NVIDIA 问题时请提供此文件。

## 三路并行

自动模式默认启用三路并行：NVENC ×1、QSV ×1、CPU ×2。任务按通道轮转分配，某通道失败后自动转交其他通道。CPU 任务数可在 1～4 间调整；每个 CPU 任务会限制 FFmpeg 线程数，避免过度订阅。

“跳过运行中”会取消当前正在编码的一批任务，后续排队任务继续；“停止队列”会停止所有运行及排队任务。手动指定编码器时保留单队列模式。

自动模式不会因启动快速测试失败而跳过 NVENC；显卡任务会依次正式尝试新版与兼容版 FFmpeg。

## 动态负载均衡

并行模式使用中央动态队列，不再按固定比例把视频预分给 CPU。所有编码器空闲后立即领取下一个未开始任务，因此快速 NVENC/QSV 会自动完成更多视频，慢速 CPU 不会形成专属积压。“等待空闲编码器”表示任务尚未被任何通道领取。
